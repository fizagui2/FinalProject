# User Stories

## Community

As a visitor, I want to browse news and forums without an account, so that I can explore GameHub before signing up.
As a user, I want to be able to post in forum chats, so that I can talk with people who have similar interests.
As a user, I want to be able to buy user listed items related to gaming, so that I can get a better deal on items.
As a user, I want to be able to reply to posts in forums, so that conversations can be engaging.
As a user, I want to be able to upvote and downvote posts, so that I can see what others think of opinions.

## Authentication

As a visitor, I want to create an account, so that I can post in forums and buy listed items.
As a signed-up or registered user, I want to log in, so that I can access my account.
As a signed up or registered user, I want to be able to add listed items to my account cart.
As a signed up or registered user, I want to be able to sign out of my account, so that I don't accidentally add items to my cart.

## Administration
As an admin, I want to login to an administration site for my website, so that I can have easy access to users and information.
As an admin, I want to be able to add news through the administration site, so that adding or ediitng news is easy.
