## Overview

GameHub is a social web application built for gamers who want to discuss games, read gaming news, and buy, sell, or trade gaming related items.

The application is divided into two primary sections:

* **Gaming Community**

  * Gaming categories
  * News articles
  * Discussion forums

* **Marketplace**

  * Listings for games, consoles, cards, accessories, and collectibles

The project follows the Agile methodology and is being developed in multiple day sprints
